## 修复 patch_android.py NameError + 剪贴板按钮链路重构（commit 3839bc6）
- CI 报错：patch_android.py 在 __main__ 块(255行)调用 patch_kotlin()，但 patch_kotlin 定义在 351 行之后 → Python 自上而下执行，调用时函数未定义 → NameError。
- 修复：把 `if __name__=='__main__'` 入口移到文件末尾(patch_kotlin 定义之后)，python 编译通过。
- 顺带确认 CI 现用 build.gradle.kts(Kotlin DSL)，patch_build_gradle/patch_min_sdk 已兼容；dependencies 块未匹配到→自动追加(无害)。
- 剪贴板「读取剪贴板」按钮链路重构（关键正确性修复）：
  - 旧：onNotificationButtonPressed 直接 `MethodChannel('native_control').invokeMethod` → 失败，因 handler 注册在主引擎、后台 isolate 是另一引擎；兜底 launchApp() 需 SYSTEM_ALERT_WINDOW 权限(多数机未授权→静默失败)。
  - 新：按钮 → `sendDataToMain('read_clipboard')` → 主 Isolate `_onClipboardLink('read_clipboard')` → `_nativeControl.invokeMethod('startClipboardProxy')`(主引擎→MainActivity handler→启动透明 ClipboardProxyActivity) → onWindowFocusChanged 获焦读剪贴板 → clipboard_proxy 通道回传 → 弹横幅。全程走主引擎，绕开两坑。
- 仍需用户 push 后看 CI：Kotlin 编译只能 CI 验证；主 Isolate 在后台能否处理 sendDataToMain 回调未经真机确认(失败则有回前台检测兜底)。
