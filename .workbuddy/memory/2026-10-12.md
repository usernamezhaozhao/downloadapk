# 2026-10-12 工作日志

- 修复 CI 构建失败：`flutter pub get` 报错 `open_filex ^5.6.0 doesn't match any versions`。
  根因：pub.dev 上 `open_filex` 最新可用主版本为 4.x，不存在 5.6.0。
  修复：pubspec.yaml 改为 `open_filex: ^4.7.0`（pub 官方建议版本）。其余依赖版本无误。
- 修复 Gradle 构建失败：`flutter_local_notifications requires core library desugaring to be enabled for :app`。
  根因：该插件用了 Java 8+ API，需在 android/app/build.gradle 开启 coreLibraryDesugaring。
  修复：在 scripts/patch_android.py 新增 patch_build_gradle()，CI 生成脚手架后自动注入
  `compileOptions { coreLibraryDesugaringEnabled = true }` 和
  `dependencies { coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.0.4") }`。
- 上一条 desugaring 修复首次未生效：原脚本只找 `android/app/build.gradle`（Groovy），
  但当前 Flutter 的 `flutter create` 默认生成 `build.gradle.kts`（Kotlin DSL），文件没找到被跳过。
  已改为同时兼容两种格式：Groovy 用 `coreLibraryDesugaringEnabled = true`，
  Kotlin DSL 用 `isCoreLibraryDesugaringEnabled = true`，依赖串 `coreLibraryDesugaring("...")` 通用。
  已用模拟 Groovy/Kotlin 文件本地验证两种注入均正确（CI 不会再白跑）。
- desugaring 二次修复：上一版开关注入了但 `dependencies` 里的 `coreLibraryDesugaring("...")` 依赖没加上，
  报 "coreLibraryDesugaring configuration contains no dependencies"。
  根因：`dependencies\s*\{` 正则没命中实际生成的 gradle 文件（模板布局不一致）。
  修复：依赖注入改为「先试插入 dependencies 块，匹配不到则在文件末尾 fallback 追加一个 dependencies 块」，
  用模拟「有/无 dependencies 块」两种 case 本地验证均成功。版本用 com.android.tools:desugar_jdk_libs:2.0.4。

## 抖音下载器 App 一期开发（一级需求）
- 后端实为 **DouK-Downloader v5.8.stable**（用户称 TikTokDownloader-master），地址 http://8.152.206.46:5555（HTTP 明文）。
  实测 OpenAPI：GET /token（健康/在线检测）；POST /douyin/share {text}→.url（解析短链）；
  POST /douyin/detail {detail_id, cookie}→.data（视频直链/图文列表/标题）；cookie 放在请求体里（非 header）。
- 存储决策（用户选）：用 gal 插件写系统相册「抖音下载」相册（MediaStore，安卓10+ 免权限，相册/文件管理器可见），
  同时在 app 私有目录 Android/data/<pkg>/files/抖音/ 留副本供列表/系统播放器打开。
- 进度条：后端 API 不返回下载进度，只在拿到直链后 App 自己 HTTP 流式下载时算进度（前端+通知双进度）。
- 失败区分：按后端返回的 message 文案分类 link_expired / parse_failed。
- 新增依赖：gal ^2.3.3、shared_preferences ^2.5.6、path ^1.9.0。gal 要求 manifest 给 WRITE_EXTERNAL_STORAGE 加 maxSdkVersion=29 且 application 加 requestLegacyExternalStorage=true（已写进 patch_android.py）。
- 代码结构：lib/models.dart(DownloadItem/MediaTask)、store.dart(持久化)、api_client.dart(后端调用)、
  parser.dart(防御式解析 detail.data→媒体任务，兼容图文/视频)、download_service.dart(下载+相册+通知)、
  douyin_page.dart(主UI)、bilibili_page.dart(Hello Bilibili)、main.dart(三Tab：抖音/B站/测试)。
- 注意：parser 字段名是防御式猜测（DouK 不同版本字段可能不同），拿到真实响应后可能要微调 parser.dart。
- 用户偏好：回复要简洁；做外网/网络请求前先说明要搜什么（本机不装 Flutter，所有构建走 CI）。
- 修复 Run tests 失败：widget_test.dart 仍断言首页 "Hello World"，但主页已重构为三 Tab（抖音/B站/测试）。重写测试：mock shared_preferences + flutter_local_notifications 平台通道后 pump MyApp，验证三 Tab 存在、点 B站 Tab 显示 "Hello Bilibili"。
