# 2026-10-12 工作日志

- 修复 CI 构建失败：`flutter pub get` 报错 `open_filex ^5.6.0 doesn't match any versions`。
  根因：pub.dev 上 `open_filex` 最新可用主版本为 4.x，不存在 5.6.0。
  修复：pubspec.yaml 改为 `open_filex: ^4.7.0`（pub 官方建议版本）。其余依赖版本无误。
- 修复 Gradle 构建失败：`flutter_local_notifications requires core library desugaring to be enabled for :app`。
  根因：该插件用了 Java 8+ API，需在 android/app/build.gradle 开启 coreLibraryDesugaring。
  修复：在 scripts/patch_android.py 新增 patch_build_gradle()，CI 生成脚手架后自动注入
  `compileOptions { coreLibraryDesugaringEnabled = true }` 和
  `dependencies { coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.0.4") }`。
- 上一条 desugaring 修复首次未生效：原脚本只找 `android/app/build.gradle`（Groovy），
  但当前 Flutter 的 `flutter create` 默认生成 `build.gradle.kts`（Kotlin DSL），文件没找到被跳过。
  已改为同时兼容两种格式：Groovy 用 `coreLibraryDesugaringEnabled = true`，
  Kotlin DSL 用 `isCoreLibraryDesugaringEnabled = true`，依赖串 `coreLibraryDesugaring("...")` 通用。
  已用模拟 Groovy/Kotlin 文件本地验证两种注入均正确（CI 不会再白跑）。
