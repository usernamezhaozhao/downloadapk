  Kotlin DSL 用 `isCoreLibraryDesugaringEnabled = true`，依赖串 `coreLibraryDesugaring("...")` 通用。

## 播放失败根因定位与修复（2026-10-12 下午）
- 用户反馈：视频下载"完成了"但无法播放。实测后端 + 抖音 CDN 定位根因：
  - `/douyin/share`、`/douyin/detail` 均正常（无需 cookie 也能拿到 `downloads` 直链，字段确为 `downloads`，type 中文「视频」）。
  - 用 Python 直连 `downloads` 直链：`Referer` 缺失 → 抖音回 403（HTML 错误页）；带 Referer+UA 但无 Cookie → 404。
  - 即 App 之前裸 GET 把 403 的 HTML 当 .mp4 存盘，导致无法播放。
- 修复（commit 0a3fe23，已本地提交，推送因沙箱 TLS 吊销检查+上行被掐未在沙箱跑通，待 push 触发 CI）：
  - download_service.dart：下载直链补 `Referer: https://www.douyin.com/` + 浏览器 UA + 透传用户 Cookie；落盘前校验 HTTP 200 且 Content-Type 非 html/json，否则直接报错并附响应片段；落盘后再按文件头魔数（mp4/jpg/png/mpeg-ts）二次校验，非媒体则删文件并抛错。
  - douyin_page.dart：新增「下载调试日志」卡片（展开可复制 HTTP 状态/Content-Type/文件头魔数），播放异常时让用户贴日志；cookie 输入框注释更正为 DouK-Downloader；下载/测试空输入回退到固定测试链接。
  - api_client.dart：新增常量 `kFixedTestLink`（用户指定那条抖音分享，懒人一键测）。
- 待办（用户已点头「可以加吧」）：flutter_foreground_task 原生前台服务防误杀。WebFetch 拉不到其最新 API 文档，故先修播放要紧项、前台服务放下一步单独稳妥接入（先核实 API 再改，避免红 CI）。
- 沙箱 git push 限制：github 上行被 TLS 吊销检查 + 出口掐断；`GIT_SSL_NO_VERIFY=true git ls-remote` 能通但 `git push` 上传 pack 会被 SIGTERM。用户在自家环境可正常 push（历史成功过）。

## 修复 CI 测试 home 空态失败（commit 002c50c）
- 根因：HomePage._load 把磁盘剩余空间查询(getApplicationDocumentsDirectory + df)放在最前，且 _loaded 仅在整段末尾置 true；flutter test 里 path_provider 无平台 handler 抛 MissingPluginException，且进度圈(CircularProgressIndicator)无限动画会让 pumpAndSettle 卡住，导致空态文案未渲染、断言找不到。

- 测试：空态用例由 pump(200ms) 改为 pumpAndSettle()，等待异步加载完成；其余两个用例不变。

## 剪贴板横幅"从不弹/只抓第一个"根因与修复（commit b50e782）
- 根因：Android 10+ 后台应用读不到剪贴板（隐私限制）。前台服务 clipboard_task 后台轮询永远拿到 null → 横幅永不弹。用户"只抓到第一个"= 仅 App 前台那次成功，后台复制全哑。
- 真正可用路径是 App 回前台时的 douyin_page._checkClipboard（App 前台系统允许读）。
- 修复：① 常驻通知文案改为实话"回到本App自动识别"，去掉误导的"复制即弹横幅"；② _checkClipboard 检测到链接后预填 _linkCtl.text + widget.onDetected 让 HomeTabs 自动切到抖音页(idx=1) + 弹横幅（显示链接）。③ SwitchListTile 副标题注明安卓10+后台受限。
- 安卓12+ 例外：前台服务后台轮询 Clipboard.getData 在该版本可返回(带隐私toast)，故服务在12+可能直接生效；10/11 只能靠回前台。
- 横幅在 App 前台时小米/华为会收进状态栏不弹，故保留 SnackBar 兜底。
