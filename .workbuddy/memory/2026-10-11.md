## Flutter Hello World 项目脚手架（CI 打包）
- 用户要求：本机不装 Flutter/Android SDK，所有脚手架生成、测试、打包都在 GitHub Action 完成；用户自己负责 git push。
- 仓库只放纯文本：`lib/main.dart`(Hello World)、`test/widget_test.dart`、`pubspec.yaml`、`.github/workflows/build-apk.yml`、`.gitignore`、`README.md`。不提交 android/ios 等原生文件。
- 工作流关键设计：CI 内 `flutter create` 生成标准脚手架（自带正确 Gradle wrapper）→ 用我们的源码覆盖 `lib/main.dart`/`test`/`pubspec.yaml` → `flutter pub get` → `flutter test` → `flutter build apk --debug` → 上传 artifact。这样保证原生脚手架与 Flutter 版本一致，避免低级错误。
- 必须的步骤：`setup-java@v4`(JDK17) + `subosito/flutter-action@v2`(stable) + `android-actions/setup-android@v3`(runner 默认无 Android SDK) + 关闭 analytics + 同意 license。打 debug APK 免签名即可安装。
- 修正：`yes | sdkmanager --licenses` 因 sdkmanager 不在 PATH 而静默失效（被 `|| true` 吞掉）；改用 `yes | flutter doctor --android-licenses` 才能正确自动同意全部 Android 许可，否则 build 卡在 `Accept? (y/N):` 失败。
- 用户偏好：做任何网络/外网搜索前先说明要搜什么。
